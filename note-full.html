6. 생활 속 기체의 부피 변화
먼저 볼 것: 무엇이 달라졌나?
누르는 힘(바깥 압력)이 달라졌다
→ 기체의 압력과 부피 관계
높은 곳에 오르내릴 때 · 물속 · 밟거나 누를 때
압력 ↑ → 부피 ↓ (반대로)
뜨거워지거나 차가워졌다
→ 기체의 온도와 부피 관계
데울 때 · 식힐 때 · 냉장고에 넣을 때
온도 ↑ → 부피 ↑ (함께)
헷갈리면 → 눌렀으니 줄고, 데웠으니 늘고
압력이 달라져서 부피가 변한 예
산 아래
높은 산
높은 산에 올라가면 과자 봉지가 부푼다
올라갈수록 봉지를 누르는 바깥 공기의 압력 ↓ → 부피 ↑
산 아래로 내려오면 반대로 줄어든다 · 봉지 속 기체의 양은 그대로
걸을 때 운동화 바닥의 공기 주머니
발이 닿는 순간 몸무게로 누르는 압력 ↑ → 부피 ↓
이때 주머니 속 공기의 압력은 커진다
물속에서 올라오는 공기 방울이 커진다
위로 올라올수록 물이 누르는 압력 ↓ → 부피 ↑
반대로 깊이 내려가면 공기 방울은 작아진다
온도가 달라져서 부피가 변한 예 ①
추운 실외
따뜻한 실내
겨울, 헬륨 풍선을 따뜻한 실내로 가져오면 팽팽해진다
풍선 속 기체의 온도 ↑ → 입자 운동 활발 → 부피 ↑
다시 추운 실외로 나가면 반대로 쪼그라든다
찌그러진 탁구공을 뜨거운 물에 넣으면 펴진다
공 속 기체의 온도 ↑ → 입자가 벽에 세게 충돌 → 부피 ↑
냉장고에 넣어 둔 생수병이 찌그러진다
병 속 공기의 온도 ↓ → 입자 운동 둔해짐 → 부피 ↓
온도가 달라져서 부피가 변한 예 ②
냉장고 달걀을 바로 삶으면 껍데기가 터지기도 한다
달걀 속 공기 주머니가 갑자기 데워져 부피 ↑
뜨거운 국그릇이 식탁 위에서 미끄러진다
그릇 밑 공기가 데워져 부피가 늘어나 그릇을 들어 올린다
물 뿜는 인형
뜨거운 물에 넣으면 인형 속 공기의 부피 ↑ → 공기가 빠져나온다
다시 찬물에 넣으면 부피 ↓ → 물이 인형 속으로 들어간다
